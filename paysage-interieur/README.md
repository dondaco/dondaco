# Ton paysage intérieur

Questionnaire pour l'atelier de tuftage : des questions sur qui tu es pour dessiner le paysage
de ton tapis (relief, eau, arbres, pierres, ciel, couleurs), avec une esquisse vue du dessus,
un portrait, et un prompt à copier (FR / EN).

Une seule page (`index.html`), sans installation. Les réponses restent dans le navigateur
(localStorage). Le bouton « Enregistrer l'esquisse » télécharge un PNG.

En ligne via GitHub Pages : `https://<utilisateur>.github.io/<dépôt>/paysage-interieur/`.
