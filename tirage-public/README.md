# Iris

Site de tirage de couleurs en une seule page (`index.html`), sans installation ni compte.
Cartes virtuelles choisies face cachée, 47 couleurs, 11 tirages, textes originaux écrits pour le site
(indépendants de tout livre ou jeu existant).

Pour le mettre en ligne gratuitement : GitHub → Settings → Pages → Source « Deploy from a branch »,
choisir la branche et le dossier racine. Le site sera à `https://<utilisateur>.github.io/<dépôt>/tirage-public/`.
