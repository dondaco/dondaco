# Tirage des Couleurs

Petite app web (fonctionne hors ligne, s'installe sur l'écran d'accueil) pour se servir plus facilement
de son propre exemplaire d'un livre + jeu de cartes de couleurs pendant un tirage.

L'app **ne contient pas le texte du livre** : tu la remplis toi-même à partir de ton exemplaire
(saisie au clavier, ou photo de la page lue par OCR directement sur ton appareil).
Tes données restent dans le navigateur de ton appareil ; pense à les exporter (Réglages → Exporter).

## Fonctions
- **Consulter** : tape le numéro de la couleur, choisis le tirage et la position → l'app affiche la bonne rubrique (Lumière, Matière…).
- **Tirage** : choisis un type de tirage, entre (ou scanne) le numéro de chaque carte, enregistre dans l'historique avec ta question.
- **Scanner** : reconnaît la carte par sa couleur via la caméra. Calibre chaque carte une fois (fiche carte → « Calibrer avec la caméra ») pour une reconnaissance fiable.
- **Cartes** : fiche par couleur (numéro, nom, couleur, rubriques, notes) + « Photo de la page » pour remplir les rubriques par OCR.
- **Réglages** : rubriques personnalisables, types de tirage (positions + rubrique à lire), création des cartes en lot, export/import.

## Mise en route
1. Ouvre l'app sur ton téléphone (voir ci-dessous) et ajoute-la à l'écran d'accueil.
2. Réglages → « Créer les cartes d'un coup » (ex. de 1 à N).
3. Réglages → adapte les rubriques et décris les tirages du livre.
4. Cartes → remplis chaque carte (photo de la page) et calibre sa couleur.

## L'ouvrir sur le téléphone
La caméra exige une adresse en `https`. Le plus simple : activer **GitHub Pages**
(Settings → Pages → branche, dossier racine) ; l'app sera alors à
`https://<utilisateur>.github.io/<dépôt>/couleurs-app/`.
